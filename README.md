# 코스트 원본

가격 원본은 [data/cost.json](data/cost.json) 하나입니다. 같은 파일을 수정하고 Git 커밋으로 변경 이력을 관리합니다. 공개 저장소이므로 비밀 값이나 서비스 설정을 올리지 않습니다.

## 사용 가능한 기준

| 기준 | 이 저장소의 가격 커밋 | 적용 시각 |
| :--- | :--- | :--- |
| 초기 등급별 공통 코스트 | `6473650876a3034cddda175c763d83bd4922e141` | 2026-07-28 00:00 KST 이전 |
| 에이전트·W-엔진별 개별 코스트 | `228f25eda4a5099c4eafe3031f60cde7f85e6ac6` | 위 시각부터 |

특정 버전은 해당 커밋의 data/cost.json을 읽습니다. 최신 브랜치의 파일을 과거 버전 대신 사용하지 않습니다. 전체 커밋 SHA를 기준으로 고정합니다.

## 파일 형식

| 필드 | 의미 |
| :--- | :--- |
| schemaVersion | JSON 구조 버전. 가격 버전과 구분하며 현재 값은 1 |
| agents[].id | 에이전트 식별자 |
| agents[].costs | 0~6돌 순서의 가격 7개 |
| engines[].id | W-엔진 UUID 식별자 |
| engines[].costs | 1~5돌 순서의 가격 5개 |

가격은 0 이상의 유한한 숫자입니다. 1.25·1.75 같은 기존 값을 보존합니다. ID는 각 그룹에서 오름차순이며 중복을 허용하지 않습니다. 현재 파일은 에이전트 62개·W-엔진 101개·가격 939개를 포함합니다.

## 변경 규칙

가격을 바꿀 때 data/cost.json만 별도 커밋으로 기록합니다. 문서·코드 변경을 가격 커밋에 섞지 않습니다. ID·가격 수·중복·정렬·값을 확인한 뒤 올립니다.

이미 사용하는 커밋은 재작성하지 않습니다. JSON에 자신의 커밋 SHA를 넣지 않습니다. 버전별 JSON 복사본이나 별도 버전 목록 파일을 만들지 않습니다. data 폴더에는 cost.json만 둡니다.

## 분리 이력

기존 가격 파일 변경 5개를 내용·순서·작성자·작성 시각과 함께 분리했습니다. 각 가격 커밋에는 이 JSON의 변경만 있습니다. 분리 과정에서 커밋 SHA가 바뀌며 원본 SHA는 커밋 메시지에 기록합니다. 기존 서비스의 원본 SHA 참조는 이 업로드로 바꾸지 않습니다.
